# Morse Code Converter (GUI)

A professional Python desktop application that converts text to Morse code
and Morse code back to text. Includes audio playback (beeps) and a dark mode UI.

## Features
- Text → Morse conversion
- Morse → Text conversion
- Morse audio playback (beeps)
- Dark mode toggle
- Clean GUI using Tkinter

## Tech Stack
- Python 3
- Tkinter (GUI)
- winsound (audio, Windows)

## How to Run
```bash
python morse-code-converter.py
